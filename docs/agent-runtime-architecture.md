# Agent Knowledge Runtime architecture

The runtime is an adapter over CERVEL's existing primitives rather than a second knowledge system. Agent observations are durable runtime records; optional assertions enter the shared claim graph. Retrieval goes through CCP assembly. Change awareness comes from Knowledge Events and downstream Impact. Proactive relevance comes from Watch.

This keeps one provenance model, one tenant boundary, one context model, and one event fabric for humans, internal agents, and external agents.
