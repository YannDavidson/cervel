# Core loop

```text
CERVEL knowledge
      ↓
permission-aware CCP
      ↓
AI agent reasoning / work
      ↓
durable Observation
      ↓ optional claim:write
CERVEL Claim
      ↓
Knowledge Evolution → Impact
      ↓
CERVEL Watch
      ↓
Agent Subscription + Receipt
      ↓
fresh CCP / next task
```

The important property is continuity across agent sessions and model replacements: CERVEL retains the durable state and the causal knowledge-change loop.
