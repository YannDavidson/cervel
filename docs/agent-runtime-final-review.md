# Final review template

**Identity:** agent principal canonical and enabled?

**Tenant:** every read/write exact Node + Workspace scoped?

**Permissions:** requested operation has an explicit capability check?

**Provenance:** observation/Claim attributable to agent + Workspace?

**Context:** CCP uses existing permission-aware assembler?

**Signals:** Events/Watch principal and Workspace scoped, bounded, idempotent?

**Regression:** all legacy lanes + Agent Runtime lane green on exact head?

Only then transition Draft → Ready for Review.
