# CERVEL as the agent knowledge plane

PR #12 establishes a clean division for future systems:

- **Agent runtime/framework:** planning, inference, tools, execution.
- **CERVEL Agent Knowledge Runtime:** identity-aware memory/context/signal interface.
- **CERVEL knowledge plane:** objects, fragments, Claims, graph, provenance, retrieval, CCP, evolution, impact and Watch.

The agent framework can be swapped while the knowledge plane remains authoritative and durable.
