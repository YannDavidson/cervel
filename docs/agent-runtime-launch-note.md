# Agent Knowledge Runtime v0.1 launch note

With PR #12, CERVEL's knowledge loop becomes agent-addressable. An authorized agent can arrive with no local conversation history, request governed context from CERVEL, perform work, return durable observations/Claims, leave, and later be reactivated by a relevant Knowledge Event or CERVEL Watch signal.

The durable memory and permission boundary remains CERVEL rather than the model vendor. This is the foundation for future CERVEL-native agents and protocol adapters.
