# Architectural positioning

CERVEL Agent Knowledge Runtime is not “memory for one chatbot.” It is a governed knowledge plane that multiple replaceable agents can use over time.

The model/orchestrator owns inference and task execution. CERVEL owns durable knowledge identity, retrieval context, provenance, Workspace authorization, knowledge change and relevance signals.

That separation is what allows a business, research system, local AI deployment or sovereign knowledge environment to change models without surrendering institutional memory to the model vendor.
