# Provider neutrality

CERVEL does not require an agent to be implemented with a particular model vendor or framework. Provider and external key are identity metadata only. The stable runtime contract is CERVEL-native: principal, Workspace grant, observation/claim, CCP, Knowledge Event, Impact, Watch, subscription, and receipt.

This allows OpenAI, Anthropic, Gemini, local models, deterministic services, and future agent protocols to share the same knowledge substrate.
