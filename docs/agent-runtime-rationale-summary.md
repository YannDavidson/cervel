# PR #12 rationale summary

CERVEL already has durable objects, graph Claims, provenance, permission-aware retrieval, CCPs, semantic reasoning, source evolution, dependency impact and proactive Watch alerts. PR #12 does not rebuild those for agents.

It adds the missing control plane that lets software agents participate safely: identity, Workspace grants, observation memory, Claim provenance and signal delivery state. That keeps CERVEL's intelligence primitives shared between humans and machines and prevents an agent-specific knowledge silo.
