# Agent Runtime terminology

**Agent identity:** metadata declaring that a CERVEL principal represents an AI/software agent.

**Workspace grant:** explicit capabilities an agent may exercise inside one Workspace.

**Observation:** durable agent memory that records what an agent noticed without automatically asserting shared truth.

**Agent Claim:** a normal CERVEL Claim created by an agent, with machine-readable agent/Workspace provenance.

**Agent context:** a normal CERVEL CCP assembled under the agent principal.

**Subscription:** a durable cursor over Workspace Knowledge Events and optionally one CERVEL Watch.

**Delivery receipt:** auditable record that a subscription surfaced an Event/alert to an agent.
